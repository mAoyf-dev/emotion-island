# 情绪探险岛：首版设计（待确认）

## 目的与使用场景
面向 6—10 岁儿童，在家长陪伴下练习辨认情绪、区分想法与事实、选择应对行动。家庭陪伴为当前设计假设；不提供诊断，不宣称治疗效果。
年龄为暂定设计目标，尚未经适龄验证。默认短句与图片，成人协助阅读；认知任务提供示范和跳过，不按年龄或表现推断能力。

## 文献审核后的约束
见 [文献与内容审核](../../content-evidence-review.md)。结论：修改后可进入心理教育原型开发，尚未通过持证专业人员逐句审核及儿童试用。
六步为可跳过的导览，不是固定心理因果链。狐狸关练习理解不确定性，积木关练习挫折应对，分别关练习接纳真实失落；后两关不强制纠正想法。
狐狸关加入明确拒绝与反复欺负的不同应对；分别限定为日常玩耍结束，不涉及死亡或创伤性分离。接纳所有情绪，同时明确不能伤害自己或他人。
身体感受不用于诊断，也不要求反复自我扫描。若有呼吸练习，只做可退出的自然舒适呼吸，不憋气、不以平静作为通关条件。
家长不考试、不强迫披露；儿童可以选择其他可信任成人。持续影响生活时建议专业评估，即时危险优先寻求现实帮助。

## 方案选择
已选：先开发“情绪探险岛”，再考虑其他游戏。
实现建议：无后端的 HTML、CSS、JavaScript 静态站点，可直接部署 GitHub Pages；当前目录为空，不引入框架或构建依赖。
备选：React 应用适合后续较复杂的模块，但首版不需要；带账号的服务增加儿童数据处理负担，暂不采用。这些实现选择是开发建议，尚待用户确认。

## 首版范围
- 首页：探险入口、陪伴提示、适用范围、理论入口。
- 三个完整故事：小狐狸加入游戏（紧张）、小熊积木倒下（挫折与生气）、小兔与朋友分别（难过）。不将场景与某种情绪固定绑定。
- 每关六步：故事 → 情绪选择 → 身体信号 → 想法与事实 → 应对行动 → 回顾及线下小练习。
- 情绪允许多选，提供“不知道”和跳过；身体感受允许“没有这些感觉”。不根据选择判定心理状态。
- 反馈解释每种行动的可能作用及限制，不惩罚表达，不设置情绪分数、排名或打卡压力。
- 可随时返回、退出、重新尝试；退出回到首页并清除本次选择。
- “不知道”与具体情绪互斥；跳过后的回顾只显示未选择，不推测感受。返回上一步保留选择，切换故事或重新尝试清空整关状态。
- “我们知道什么，还有什么不知道”：先区分事件、感受与脑中的话，再检查故事是否提供证据；不将感受判错，不将“想法”和“未知”当作互斥类别，不对真实失落强制寻找积极解释。
- 家长页：先接纳再讨论的提问范例、停止条件、专业支持边界。
- 理论页：逐项解释机制、来源、适用限制和未验证状态。

## 视觉与无障碍
以实际浏览的 Khan Academy Kids Camp 页面为样式参考（2026-11-11），不沿用营地主题：白色导航、浅青色首屏（#aff1f6）、左侧标题与右侧白色开始面板、深蓝主按钮（#0a2a66）、白色介绍区、浅蓝故事区（#eaf8fd）、两列大插图及薄荷绿次按钮（#109d7b）。参考的是布局、配色与留白，不复制表单、机构品牌、角色或原图。故事插图重新生成，各自表现具体情节，保存在 assets/stories/；表情与底部植物为本地 SVG。故事正文桌面 24px、手机 22px。手机优先，大按钮，清晰焦点，键盘可操作；减少动态设置下关闭装饰动画。不依赖颜色传递意义，不自动播放声音。首版无录音或语音合成。

## 理论与内容规则
CBT 提供情绪、身体反应、想法和行动的联系及替代解释框架；儿童中心游戏治疗提供自主选择与接纳的设计原则。结构化选择题属于心理教育练习，不等同于非指导性游戏治疗。
理论卡对每关记录目标、交互、依据、成人提示、边界。反馈不使用“别难过”“你想错了”，允许情境中多个合理解释。角色担心被拒绝时，也要承认拒绝可能发生，提供安全应对和求助方式。
不从作品、颜色、点击或身体反应推断疾病；不加入创伤回忆、自动暴露任务、AI 咨询或诊断量表。

## 数据与发布
无账号、无统计脚本、不上传或持久化儿童选择。选择只在页面内存保存，刷新后消失。第三方平台的访问日志不属于应用可控制的数据范围。
交付源代码、README、理论说明、内容审核清单、MIT 代码许可和 GitHub Pages 发布配置。插图自行绘制并说明许可，不复制文章图片或课程材料。
用户已提出 GitHub 发布目标；实现后检查本地 Git/gh 可用性及登录状态，在现有授权范围内发布。若缺少账号访问或仓库归属信息，如实报告并请求必要信息，不伪称发布成功。

## 验证与验收
用小型自动检查覆盖故事数据完整性、流程转换、多选、跳过、退出和重开；浏览器检查手机与桌面布局、键盘操作、理论链接和控制台异常。没有可用浏览器时明确说明未完成视觉验证。
验收：三个故事均可从入口走到回顾，能够退出和重来，无强制正确情绪、无个人数据提交；GitHub Pages 路径下静态资源可加载。
初版只验证功能与内容一致性；儿童可用性、专业审核及临床效果需后续独立验证。
